# Yuri Math RPG (小一數學奧術冒險)

一個專為小學一年級（Grade 1）設計的沉浸式 RPG 魔法算術冒險遊戲。啟發自經典魔導題材，結合香港小學一年級最新數學課程標準。

---

## 🌟 遊戲特色

1. **小一數學專項（HK Primary 1 Syllabus）**：
   - 20 以內加法與分解合成（螢火蟲森林）
   - 相差比較與應用題（海難海岸）
   - 連加連減與括號填空（黑曜石火山峰）
   - 奇數偶數、十格陣與數線（寒顫雪山）
   - 混合心算與守護結界破譯（浮空風暴城）
   - 題目隨機生成，每次進入皆有全新題目！

2. **五大元素王國與野生精靈生態**：
   - 螢火蟲森林 (Firefly Forest)
   - 海難海岸 (Shipwreck Shore)
   - 篝火火山峰 (Bonfire Spire)
   - 寒顫雪山 (Shiverchill Mountains)
   - 浮空風暴城 (Skywatch)
   - 燈火主城 (Lamplight Town)

3. **正統精靈收服與進化系統**：
   - 初始精靈契約：Hotpot (火罐幼獸)、Squiddle (墨汁小魷)、Peeko (草苗雀)、Snoot (雪鼻獸)、Cloudling (雷雲獸)
   - 戰鬥中削弱野生怪獸體力至 45% 以下即可使用淨化法術收服入隊
   - 戰鬥勝利獲取 XP 升級並觸發奧術進化！

4. **現代響應式與 iPhone 橫屏優化**：
   - 完整支援 iPhone 橫屏（iPhone 13 ~ 16 Pro Max 全系列）
   - 零畸變 1:1 精確比例渲染（杜絕拉伸扁平問題）
   - 觸控虛擬十字鍵與點擊移動雙重操作支援

## 🚀 本地開發與運行

```bash
# 安裝相依套件
npm install

# 啟動本機開發伺服器
npm run dev

# 建置發布版本
npm run build
```
